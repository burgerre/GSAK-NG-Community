# Sprachen / Languages

## Deutsch

Die Homepage, die Einstiegsseiten zu Makros und Community sowie die Katalogbedienung bleiben in allen 11 Zielsprachen verfügbar. Dazu gehören Suche, Kategorien, Schaltflächen und Statushinweise.

Neue makrospezifische Beschreibungen, Anleitungen und Änderungsinformationen starten mit Deutsch und Englisch. Bestehende zusätzliche Übersetzungen bleiben erhalten; weitere können später ergänzt werden. Die Sprache eines Diskussionsbeitrags wird mit [DE] oder [EN] im Titel gekennzeichnet. Beitragsleitfaden, Themenvorlagen und technische Communityunterlagen werden zunächst auf Deutsch und Englisch gepflegt.

Wenn eine Beschreibung nicht in der gewählten Oberflächensprache vorliegt, wird Englisch, danach Deutsch angeboten und als solche gekennzeichnet. Eine englische Beschreibung unter französischer Bedienung ist keine französische Übersetzung. Fehlende Inhalte werden nicht erfunden und nicht als übersetzt gemeldet. Reine Makronamen und technische Kennungen müssen nicht künstlich übersetzt werden.

Der Makrokatalog enthält derzeit keine freigegebenen Makros. Diese Sprachregel beschreibt den Beitrags- und Darstellungsprozess; sie ist keine Zusage einer bereits vorhandenen Makroversion oder einer App-Installation.

## English

The homepage, macro/community entry pages and catalogue interface remain available in all 11 target languages, including search, categories, buttons and status messages.

New macro-specific descriptions, instructions and changelogs start in German and English. Preserve any existing additional translations; more can be added later. Use [DE] or [EN] title prefixes for discussions. Contribution guidance, prompts and technical community documents are initially maintained in German and English.

If a description is unavailable in the selected interface language, offer English, then German, with a visible language label. English content within a French interface is not a French translation. Never invent missing content or report it as translated. Proper macro names and technical identifiers do not need artificial translations.

There are currently no approved macros in the catalogue. This policy defines contribution and display behaviour, not an existing macro release or app installation feature.
