# GSAK-NG Community

Makros, Fragen, Ideen und Erfahrungen rund um GSAK-NG. / Macros, questions, ideas and experiences around GSAK-NG.

## Willkommen / Welcome

**Deutsch:** Die Community ist über [GitHub Discussions](https://github.com/burgerre/GSAK-NG-Community/discussions) erreichbar. Lies mit oder verwende dein bestehendes GitHub-Konto zum Mitschreiben. Ein zusätzliches GSAK-NG-Konto ist nicht nötig. Für private Wünsche bleibt das [Wunschformular](https://gsak-ng.com/wuensche.html) ohne GitHub-Konto verfügbar.

**English:** Join [GitHub Discussions](https://github.com/burgerre/GSAK-NG-Community/discussions) to ask questions, exchange ideas and propose macros. Reading does not require a separate GSAK-NG account; posting uses your GitHub account. For private feedback, use the [wish form](https://gsak-ng.com/wishes-en.html).

## Makrobibliothek / Macro library

Der freigegebene Katalog ist zunächst leer. Es werden keine fiktiven Makros, Downloads oder Testbehauptungen angeboten. Künftige Makrodateien erhalten eigene Versionen, Lizenzen, Anleitungen und konkrete Kompatibilitätsnachweise. Heruntergeladene Makros werden nicht automatisch ausgeführt.

The approved catalogue is initially empty. There are no fictional macros, downloads or test claims. Future macro files will have explicit versions, licences, instructions and scoped compatibility evidence. Downloads are not executed automatically.

Die Webseitenbereiche **gsak-ng.com/makros/** und **gsak-ng.com/community/** werden separat vorbereitet und sind noch nicht veröffentlicht. / Dedicated website pages are being prepared separately and have not been published yet.

## Rechte und Umfang / Rights and scope

Keine pauschale Lizenz für fremde Makros. Ein Beitrag benötigt einen eigenen Lizenztext und belegte Weitergaberechte. Öffentliche Abrufbarkeit allein erlaubt keine Übernahme aus anderen Makrobibliotheken. Das Vorhandensein im Katalog ist keine allgemeine Sicherheits- oder Kompatibilitätsgarantie.

No blanket licence covers third-party macros. Contributions require their own licence and established redistribution rights. Public visibility alone does not permit copying another macro library. Listing is not a blanket safety or compatibility guarantee.

Dieses Repository ist ein öffentlicher Communitybereich, nicht der Programmquellcode von GSAK-NG. Direkte Installation und Updateanbindung in der App sind ein späterer Ausbauschritt, keine bereits zugesicherte Funktion dieses Katalogs.

This is the public community space, not the GSAK-NG application source code. Direct app installation and update integration are a future step, not an existing capability of this catalogue.
